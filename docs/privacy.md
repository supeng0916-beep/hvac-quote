# 数据与隐私边界

公开版使用独立目录和全新 Git 历史。仓库只包含通用源码、合成测试、演示生成器和从合成数据运行所得的页面截图。

已移除企业名称与标识、客户和工程档案、真实图纸与报价附件、专用工程量配置、内部价格基准、账号数据库、日志、备份、部署地址及历史记录。演示数据从代码重新生成，不由客户资料替换姓名或缩放金额得到。

## 对功能的影响

| 处理 | 公开版行为 |
| --- | --- |
| 删除专用项目档案和预设工程量 | 从自行上传的图纸建立草稿，人工确认数量与范围 |
| 清除企业与客户标识 | 页面、PDF、工作簿使用 HVAC Quote 通用名称 |
| 移除特定设备安装费豁免规则 | 按确认的材料价与安装价计算 |
| 不沿用内部税率 | 默认税率 0，生成前自行确认 |
| 移除内部模板布局依赖 | 导入表可映射价格列；输出新建统一格式 Excel |
| 清除账号、密钥和业务运行状态 | 首次运行自行创建账号，外部服务自行配置 |
| 移除试用授权机制 | 本地账号和项目权限保留，无内部授权服务器依赖 |

## 运行后产生的数据

上传文件、客户信息、账号配置、数据库、输出报价和演示随机密码都属于运行数据，不是公开仓库内容。默认 `data/`、`runs/`、环境文件、数据库和日志已加入忽略规则；自定义输出目录时需同步检查忽略规则。不要把真实运行目录、日志或未经核对的截图提交到仓库。

普通流程在本地解析和计算。可选视觉功能开启并提交后会向配置的外部服务发送选定局部与相关上下文；演示和仓库截图未启用该功能。

公开版不携带历史客户文件，但部署后由用户上传的文件不会自动脱敏。对外分享报价、截图或问题复现资料前，仍需检查其实际内容。
